Для того, чтобы компилятор мог узнать о классах, входящих в архив Pokemon.jar, о месте их
нахождения нужно сообщить компилятору.
javac -cp ./Pokemon.jar:. Main.java

Опция -cp задает список путей, где компилятор будет искать классы. В данном случае это архив
Pokemon.jar и текущий каталог (обозначающийся точкой). В конце указываем какие классы
нужно откомпилировать — Main.java.

После компиляции запустим получившийся класс Main:
java -cp ./Pokemon.jar:. Main
